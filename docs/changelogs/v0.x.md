## v0.1.0 — Initial release

First public release of `orderselect` — an ordered multi-select prompt for Rust
CLIs that lets users **select a subset** of options and **preserves the order**
in which they were toggled.

### Added

- **`OrderedSelect<T>`** builder API with toggle-order tracking — the first
  item toggled is first in the returned `Vec`.
- **Terminal-aware rendering**: queries `terminal::size()` each frame; truncates
  long option text with `…`, clamps page size to terminal height, switches to
  compact help line (`↑↓/sp/a/n/enter/esc`) when width < 50.
- **Raw-mode `\r\n` fix**: all output uses `\r\n` to avoid the staircase
  indentation bug in raw mode (affects mobile/narrow terminals).
- **CLI binary** (`--features cli`): reads options from args or stdin, outputs
  selected items newline-separated in toggle order. Exit codes: 0 success, 1
  error, 2 not a terminal, 130 cancelled.
- **Custom symbols**: `Symbols { cursor, checked, unchecked }` +
  `ASCII_SYMBOLS` const for environments without Unicode support.
- **Builder methods**: `with_defaults`, `with_help_message`, `with_page_size`,
  `should_loop`, `with_symbols`.
- **Error type**: `Error { NotATerminal, Cancelled, Io, EmptyOptions,
  InvalidDefault }` via `thiserror`.
- **Pagination**: cursor-centered scrolling with configurable page size.
- **10 unit tests** + 1 doctest, clippy `-D warnings` clean.

### Dependencies

- `crossterm` 0.28 — terminal rendering (same backend as `inquire`, coexists
  without conflicts).
- `thiserror` 2 — typed errors.
- `clap` 4 (optional, `cli` feature) — CLI binary arg parsing.
